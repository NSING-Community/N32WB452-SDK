# N32WB452-SDK

> Imported version: **v2.6.0**  
> Original package directory: `Nations.N32WB452_Library.2.6.0`

## Overview

**N32WB452-SDK** is the firmware development kit for the N32WB452 microcontroller family, maintained by NSING-Community. It preserves the firmware libraries, example projects, middleware, and tools supplied with the source package.

## Top-level contents

- `.git/`
- `.vscode/`
- `firmware/`
- `jlink/`
- `middlewares/`
- `projects/`

## Usage

Clone the repository, then open the appropriate Keil MDK, IAR EWARM, or GCC project under `projects/`, `RVMDK/`, or the relevant project directory. Refer to the documentation included with each example for board connections and expected behavior.
